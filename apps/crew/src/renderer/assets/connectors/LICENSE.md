# Connector logos

The SVG files in this folder are taken unchanged from [simple-icons](https://github.com/simple-icons/simple-icons)
version 16.38.0 (`https://cdn.jsdelivr.net/npm/simple-icons@16.38.0/icons/<slug>.svg`), which is
released under CC0 1.0 (no rights reserved). Each brand colour is the `hex` in that release's
`data/simple-icons.json`, copied into `connectorLogos.ts`.
