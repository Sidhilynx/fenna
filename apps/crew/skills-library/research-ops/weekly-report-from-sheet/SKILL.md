# Weekly report from a sheet

1. Open the sheet the person names with the Sheets tools. Read the header row and the last two weeks of rows.
2. Work out each key figure's change from last week, in numbers and in percent. Round only in the last step.
3. Pick the three changes that matter most, good or bad.
4. Flag anything off target, or changed by more than 20 percent, and name the row it came from.
5. Write the report: one line on the week, the three changes, the flags, and what is planned for next week.
6. Put the report in a doc titled with the week's date.

Output: a doc with the report. Do not change the numbers in the sheet.
