# Meeting minutes

1. Read the meeting record, transcript or notes from Files or the meetings record.
2. Write the header: the meeting's name, the date, who was there, and who wrote the minutes.
3. List the decisions, one line each, with the reason when one was given.
4. List the actions as owner, task and due date. If no date was set, write "no date set". Do not invent owners.
5. List what is still open, and anything parked for later.
6. Keep the minutes to one page.

Output: a doc titled with the meeting's name and date, with sections for attendees, decisions, actions and open items.
