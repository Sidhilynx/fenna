# Rewrite for clarity

1. Read the whole draft before changing anything. Note the reader and the purpose, if the person gives them.
2. Keep every fact, number, name and link. Do not add a claim that is not in the draft.
3. Shorten sentences that carry more than one main idea. Put the point first.
4. Replace jargon and abbreviations the reader may not know, or explain each one once.
5. Cut repeated points and filler words.
6. Return the rewrite, then the three biggest changes, and any sentence whose meaning you were not sure of.

Output: a doc with the rewritten text first, the change list under it, and the original below a line so the person can compare.
