# Pitch deck outline

1. Read the product notes, the market notes and any numbers in Files. Note what is known and what is assumed.
2. Outline 10 to 12 slides in this order: problem, why now, solution, product, market size, traction, business model, competition, team, the ask.
3. For each slide, write one title that states the point, such as "Teams lose two days a week to status meetings", and two to four bullets of proof.
4. Mark every number that has no source as "to confirm".
5. List what the deck does not yet show, so the person knows the gaps before an investor finds them.
6. Write the outline to a doc with the Docs tools. If the person asks, make a placeholder deck with the Slides tools, one slide per outline item.

Output: a numbered outline in a doc. Each slide has a title and bullets. The doc ends with a short list of gaps.
