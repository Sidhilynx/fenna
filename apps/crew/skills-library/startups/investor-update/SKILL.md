# Investor update

1. Read the notes and numbers the person gives you, in Files or in the chat. If a figure is missing, leave a marked gap. Do not guess.
2. Write the update in this order:
   - Headline: one sentence on how the month went.
   - Numbers: revenue, spending, cash left, runway, customers or users. Use the same definitions as last time.
   - Wins: three at most, each with its result.
   - Problems: what went wrong and what is being done about it.
   - Asks: the one or two things you want from investors. Name the person or the introduction.
3. Keep it under 500 words. Use plain sentences.
4. Put the draft in a doc with the Docs tools, titled with the month.
5. If there was an update before, compare its numbers with this one using the Sheets tools. List any change over 10 percent in a note at the end for the person to check.

Output: one doc titled "Investor update, <month and year>" with the sections above, and a short note to the person listing the gaps and the changes to check.
