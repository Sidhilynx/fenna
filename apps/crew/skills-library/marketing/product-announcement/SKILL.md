# Product announcement

1. Read the release or feature notes in Files. Find the one change a user would care about most.
2. Write a headline that names that change in plain words. Avoid superlatives.
3. Write the post in this order: what is new, why it matters to the reader, how to try it, and what did not change. Keep it under 400 words.
4. Write a two-sentence version for social posts and a one-line version for a newsletter.
5. Check every claim against the notes. Remove any claim with no source, or mark it "to confirm".
6. Put the post in a doc with the Docs tools, with the short versions under it.

Output: one doc with the full post and the short versions, and a list of claims to confirm, if there are any.
