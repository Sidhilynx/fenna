# SEO brief

1. Ask the person for the topic and the page's goal in one sentence. If the goal is missing, ask before going on.
2. Search the topic with the browser and open the top five to eight results. Read them. Do not copy their text.
3. Note the question the pages answer, the sections most of them share, and the questions none of them answer.
4. Pick one main search phrase and three to five related phrases. Base any view of them on the search results only, and say so. Do not state search volumes you have not seen.
5. Write an outline of six to eight headings, each with the point it has to make.
6. Suggest a page title under 60 characters and a description under 155 characters.

Output: a brief in a doc with the goal, the main phrase, the related phrases, the outline, the title, the description, and the links to the pages you read.
