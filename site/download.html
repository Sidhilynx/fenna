First start

The app isn't signed yet, so your system asks once.

  • Windows

    "Windows protected your PC" → More info → Run anyway.

  • macOS

    Open the app once, then System Settings → Privacy & Security → Open Anyway.

  • Linux AppImage

    Make it executable (chmod +x Fenna-*.AppImage), then run it.
