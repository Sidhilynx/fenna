# Security

## Reporting a problem

Please don't report security problems in public issues. Use GitHub's private
reporting instead:
**[Report a vulnerability](https://github.com/Sidhilynx/fenna/security/advisories/new)**
(Security tab → Report a vulnerability).

Say which app and version, what an attacker could do, and how to reproduce
it. We'll reply within a week, keep you told of progress, and credit you in
the release notes if you'd like.

## What counts

Fenna opens files people receive from others, and lets an AI edit them, so
we care most about:

- a file (deck, doc, sheet, board, or an imported PowerPoint, Word or Excel
  file) that runs code, reads other files, or reaches the network when opened;
- an AI, through the MCP tools, reaching anything beyond the one open file;
- a way around the checks on downloads (updates, AI apps installed from the
  chat).

## Supported versions

Only the latest release gets fixes. Home shows when a newer one is out.
