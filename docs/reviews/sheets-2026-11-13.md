# sheets review, 2026-11-13

Reviewer: Claude Opus 5.5  Stage: finish  Commit: c3df0b9 (plus uncommitted work)

## Summary
The builder's sheets app had the grid, a format, formulas, a toolbar, cell
types, charts and rules, but structural edits broke formulas, dates and
locales were half done, menus and panels did not match the reference, and
the MCP server was a draft. After this pass, each of the 39 reference
screens was checked against our captures, and each state exists in the
app. Structural edits move every
formula, rule, chart, filter, group and comment that points at the changed
cells. The MCP server was redesigned and passes all four agent tasks with
two models. No blocker or major finding is open.

## Edge cases
Captured and checked:
- empty workbook (light, quick bar);
- 300 sheets with very long titles (tabs and the sheet list ellipsize; the list scrolls);
- a 100,000-row sheet: load, Ctrl+↓ to the end, an edit saved, the whole-column SUM updated;
- a broken sheet file: a banner says what to do, the file is left as it is on disk, and other sheets still save;
- keyboard-only grouping (Alt+Shift+→), insertion (Ctrl+Alt+=), and arrows skipping collapsed and filtered rows;
- 1000×700 with the chat open;
- both themes for every flow above.
