Three steps, each one usable on its own. Dates are targets, not promisesand may move a week.

1. Write and read

The editor handles headings, lists, tables, images and code. Typing never waits on a save: the page saves itself a moment after you stop.

  • Blocks and marks in the format
  • Markdown shortcuts while typing
  • Paste from the web without stray styles

2. Work with the assistant

The assistant edits blocks by id, so it changes only what you asked about. Its edits appear on the page as they land. In Suggesting mode they arrive as suggestions for you to accept or reject.

{ "op": "replace", "block": "step-2-p", "html": "<p>…</p>" }

  3. Export Markdown for the repo
