Fenna Docs is a document editor that runs on your own computer. Your files stay in a folder you choose, and any AI that speaks MCP can read and edit them while you watch.

Why a local doc editor

Most writing tools keep your documents on someone else's server and decide which AI you may use. Fenna Docs keeps each doc as plain files in a folder: one HTML file per tab, a small doc.json for settings, and an assets folder for images.

The doc should outlive the app. Open the folder in any text editor and it still reads.

What ships first

  • Tabs and nested tabs, with an outline of each tab
  • Comments you can send to the assistant
  • Suggesting mode: edits become suggestions to accept or reject
  • Export to Word, PDF, Markdown and HTML
